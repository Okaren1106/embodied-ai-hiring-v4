# 论文 v1.4 复算

Python 3.10及以上，在任意目录运行：

```text
python /path/to/reproduce/reproduce.py --output /path/to/new_output
```

输出目录必须不存在，并位于本复算目录之外。基础计算只使用Python标准库，不访问网络或原工作区。
程序先核对文件哈希，再复算原稿8表并核对继承表，随后重建496个广告—技术对应项、六指标汇总、120个公司点、活动双向表、四职能分量、情景成员变化及修订稿15张表，其中表1b为测量规则简表。
图形可加 `--figures`，需要matplotlib与numpy；中文字体需在使用环境中可用。不同绘图版本可能改变图像字节，数值结果不受影响。

输入为已完成编码的固定资料。此包重建统计连接和计算，不重新判读全部广告。三任务248条广告的三个冻结原字段及全部相关证据随包保留，可重建evidence目录中的语境页面与索引。
`base_v1_0`保存原稿复算协议及输入，保留原始来源、版本和贡献记录。它的旧表名仅用于复算核对，正文以本版表号为准。

`ad_context_correspondence.csv`中M_positive仅表示技术提及正例；为0不能直接判作M层的Z。G状态独立定义。P/Z/U状态互斥；仅职责、仅优先、必备、任选、示例、未解分支等标志可以重叠，不能相加作原因比例。

表5c新增的P/提及数直接由联合计数生成；原表6移为附表A2，T5资产键及其20行数值保持。
