## Scope and length

All 15 source-table assets (108 rows) and all three figures are preserved. Two pairs of source tables form panels in the five numbered main tables; eight tables and one figure are supplementary. The main text contains 4,721 Word-counted words. A conservative count that also includes the 1,052 literal table words and 280 words for each of seven numbered main displays is 7,733. The abstract, keywords and classification contain 223 regex-counted words. These are documented counts, not a claim about the submission system's own calculation.

This is a descriptive purposive-sample study. Advertisement counts, recorded activity and semantic qualifications retain their separate meanings; the rewrite introduces no new empirical results, causal estimates, reliability claims or population inference.
