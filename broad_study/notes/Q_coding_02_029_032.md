[full_description]
L1 【岗位职责】

## 32 N0480 CN_FOURIER 硬件研发工程师
[full_description]
L1 岗位职责：
L2 1. 负责公司人形机器人核心硬件系统的方案设计与开发，涵盖主控板、电源系统、传感器接口、驱动控制相关硬件模块。
L3 2. 主导硬件架构设计、关键器件选型、原理图设计、PCB评审、样机调试与测试验证，推动硬件方案持续优化。
L4 3. 参与整机级硬件系统集成，与结构、嵌入式、控制算法、测试等团队协作，完成复杂问题定位、联调与闭环。
L5 4. 负责硬件可靠性、稳定性、一致性及可量产性设计，提升系统在功耗、EMC、热管理、抗干扰等方面的综合表现。
L6 5. 针对机器人关节模组、传感器、电池管理、通信接口等关键模块开展技术攻关与性能优化。
L7 6. 推动研发成果向工程化和量产转化，输出设计规范、测试方案、调试文档、BOM及相关技术资料。
L8 7. 持续关注机器人硬件、智能执行器、嵌入式系统、电源与传感技术的发展趋势，并推动新技术在产品中的落地。
L9 任职要求：
L10 1. 本科及以上学历，电子工程、自动化、电气工程、通信、测控、机电等相关专业。
L11 2. 具备3年以上硬件研发经验，有机器人、工业自动化、智能硬件、伺服驱动、控制器等相关领域经验者优先。
L12 3. 能够独立负责复杂硬件模块或系统的设计开发，具备较强的系统分析能力和工程落地能力。
L13 4. 熟悉模拟电路、数字电路设计，具备完整的器件选型、原理图设计、调试验证及问题分析能力。
L14 5. 熟悉 CAN、RS485、SPI、I2C、UART、Ethernet 等常见通信接口及相关应用场景。
L15 6. 熟悉电源设计、EMC/EMI、ESD防护、热设计、信号完整性等关键硬件设计要点。
L16 7. 熟练使用示波器、逻辑分析仪、电源、万用表等仪器进行调试和故障定位。
L17 8. 具备较强的跨团队协同能力，能够推动硬件问题高效解决，并支撑整机系统快速迭代。
L18 加分项：
L19 1. 有人形机器人、四足机器人、协作机器人或高自由度机电系统研发经验。
L20 2. 有关节驱动器、伺服控制器、电机控制、电池管理系统（BMS）相关开发经验。
L21 3. 有小型化、轻量化、高集成度、低功耗硬件设计经验。
L22 4. 有从样机开发到量产导入的完整项目经历，熟悉DFM/DFT及供应链协同流程。
L23 5. 有软硬件协同开发经验，能够与嵌入式、控制、算法团队高效协作。
L24 我们希望你是这样的人：
L25 1. 对机器人行业有热情，愿意面对复杂系统挑战，也乐于深入一线解决实际问题。
L26 2. 具备较强的自驱力和探索欲，能够在不确定性中持续推进工作。
L27 3. 不只关注模块本身，也能从整机和产品视角思考方案优劣。
L28 4. 乐于分享与协作，愿意在开放直接的沟通环境中共同成长。
L29 团队与岗位亮点：
L30 1. 团队氛围开放、务实、自由，鼓励表达观点、尝试新方案，也尊重每个人的专业判断。
L31 2. 有较大的学习和成长空间，你可以深度参与人形机器人核心硬件系统研发，接触复杂整机架构与前沿技术问题。
L32 3. 强调协作和快速迭代，硬件工程师不仅是执行者，也能真正参与技术路线、产品方案和工程决策。
L33 4. 在高速发展的机器人赛道中，你将有机会承担更核心的职责，持续拓展技术深度与业务影响力。
