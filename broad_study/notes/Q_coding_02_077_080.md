## 78 E0166 CN_XSQUARE 相机架构师
[full_description]
L1 岗位职责
L2 1. 图像传感器（Sensor）选型与底层评估
L3 - 负责根据系统级需求（运动速度、暗光条件、信噪比要求）进行 Sensor 芯片的技术选型（覆盖 Global Shutter / Rolling Shutter，如豪威 OS/OG 系列、索尼 IMX 系列）；
L4 - 深度量化 Sensor 底层物理参数，评估其像元尺寸（Pixel Size）、动态范围（DR）、量子效率（QE）、近红外（NIR）感光度及主光线角（CRA）等关键指标。
L5 2. 光学与镜头选型（Optics Selection）
L6 - 根据 Sensor 规格、视场角（FOV）及工作距离，进行镜头（M12 / C / CS mount 等）的选型与定制；
L7 - 从物理光学角度评估成像质量，包括像差控制、衍射极限评估（艾里斑与像元匹配计算）、镜头畸变（Distortion）曲线以及 CRA（主光线角）匹配性。
L8 3. 相机模组设计与硬件开发（Module Design）
L9 - 主导或参与 Camera 模组（SerDes 传输、软硬结合板 Rigid-Flex）的电路原理图设计与 PCB Layout 审查，处理高速差分信号（MIPI CSI-2, GMSL2/3, FPD-Link）的信号完整性（SI）及电源完整性（PI）；
L10 - 负责模组的散热结构设计、EMC/EMI 优化以及结构干涉评估。
L11 4. 视觉时钟与多目时间同步（Time Synchronization）
L12 - 设计多目相机（Stereo / Multi-camera）系统的硬同步机制（Hardware Trigger），打通 FSYNC/VSYNC 控制链路；
L13 - 解决相机与高频 IMU、LiDAR（激光雷达）或主控 SoC 之间的微秒级（$$\mu\text{s}$$）时间戳对齐与硬件触发（Strobe / Exposure 脉冲控制）。
L14 5. 图像质量（IQ）客观标定与交付
L15 - 配合 ISP 算法团队，利用测试靶卡（ISO12233、24色卡、均匀光源箱）对模组进行客观指标量化测试（SFR/MTF、Noise、Lens Shading、Color Shading）；
L16 - 负责生产线上 Lens Mount 的 6 自由度主动对齐（Active Alignment, AA）工艺对接与出厂标定标准制定。
L17 任职要求
L18 1. 教育与工作背景
L19 - 光学工程、微电子、电子信息、自动化或计算机视觉相关专业，本科及以上学历；
L20 - 3 年及以上 相机模组研发、工业相机设计、自动驾驶车载摄像头或具身智能视觉硬件开发经验。
L21 2. 核心硬技能（必须具备）
L22 - 深厚的光学与成像底子：熟知几何光学与波动光学原理，能用数据定量推导光圈（$$F$$ 值）、曝光时间、衍射极限与画面清晰度/噪点之间的因果关系；
L23 - 硬件电路功底：熟悉 MIPI 协议，具备高速信号或解串器（GMSL/FPD-Link）PCB 设计或 Debug 经验，熟练使用示波器、逻辑分析仪分析信号抖动；
L24 - 时间同步实战：拥有多相机硬同步触发、脉冲宽度调制（PWM）控制外置红外补光灯（Strobe）的实际工程落地经验。
L25 3. 加分项（优先录用）
L26 - 有车载、全自主导航机器人（VIO/SLAM）或多目立体匹配（Stereo Matching）项目视觉硬件总师经验者优先；
L27 - 熟悉 Imatest 等主流图像质量分析工具，了解 LSC（镜头阴影校正）、Sharpening（锐化）等基础 ISP 算法流
