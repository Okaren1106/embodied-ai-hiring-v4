# Exploratory PyTorch–TensorFlow framework control

This after-discovery extension keeps the105 robot-model advertisements and applies the same qualification constructs to two frameworks. It is a within-corpus measurement control, not independent human validation or a representative demand estimate.

Read `audit/framework_control_review.md` for results and limits, and `prospective_extension_decisions.md` for decisions and the amendment trail. Current primary results are the `harmonized_framework_control` version in `outputs/framework_contrasts.csv`. The inherited comparison remains a comparability diagnostic; after the coordinator's main-layer correction the versions coincide.

Run with Python3.10 or later, standard library only, from the v4 root:

```text
python extensions/framework_control/scripts/run_framework_control.py
```

The script also rebuilds the literal inventory and local source packet. Paths resolve from the script location. Inputs are frozen `source_snapshot/`, the current v4 qualification scope/overlay, and this extension's review annotations. It writes only to this extension's `outputs/`. Rebuild the main v4 scope first if inputs changed; no live web or original database is needed.

`data/source_review_annotations.json` holds26 model full-source review decisions. It is a reproducibility input, not programmatically verified semantic truth. The other79 advertisements were checked for TensorFlow across every captured duties, requirements and full-description field. PyTorch classifications outside the26 co-mentions remain inherited.

Key outputs:

- `tensorflow_states_105.csv`: complete target-state ledger, including79 literal absences.
- `source_review_26.csv`, `matched_full_sources.md`, `matched_source_packet.json`: source text, context, branch, offsets, hashes, and same-predicate evidence.
- `all_field_literal_checks.csv`, `source_integrity_checks.csv`: exhaustive field inventory and target/parent-span checks.
- `paired_states_105.csv`, `framework_contrasts.csv`: five constructs in all105 and26 co-mentions.
- `coupled_reading_diagnostic.csv`: separate named equality assumptions for shared unresolved expressions; primary tables retain outer bounds.
- `summary.json`, `source_inventory_manifest.json`: counts/checks/input hashes.
- `pre_main_consistency_history/`: superseded N0798 discrepancy and earlier uncertainty scenario; never use as current results.

The26 co-mentions show identical individual states for the two frameworks and no ranking reversal. All results, including the zero differences, are reported. Extension scripts do not modify the manuscript, source snapshot or original496-pair production labels.
