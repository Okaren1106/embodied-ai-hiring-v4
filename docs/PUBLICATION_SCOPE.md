# 公开发布范围、版本与引用

发布日期：**2026-10-09**。

本仓库公开的是转向申请表研究前的 **V4.0** 研究阶段。本项目还曾用 v0.x 标记分类规则；这里的 V4.0 指英文研究稿及其分析版本，由“申请表转向之前”这一阶段定位确定。

## 包含的研究

1. **完整的原始招聘研究**：24 主体、1,654 条广告，主职能、跨职能活动、资格目录、四公司 84 条工作对象分析、公司构成分解、全部输入、证据、修订记录、查询页和结果表。
2. **V4 英文研究**：248 广告、496 技术记录的资格构造比较，配对、公司与文本权重、语义范围、分类变化距离以及 PyTorch—TensorFlow 扩展。
3. **全部相关论文材料**：中文综合报告，V4 主文、阅读版、表格与补充材料的 Word／PDF／Markdown；V1—V3 的英文论文与原始 ZIP 包。
4. **复算与追溯材料**：原工作脚本、冻结协议、阶段记录、文献与核验，以及新增的便携复算、无损恢复和文件校验入口。

后续申请表、V7 与 V8 研究属于不同阶段。公开包的范围到 V4 为止。

## 与原始交付的关系

`archives/` 保留 V1—V4 原 ZIP 字节。`paper_v4/` 由 V4 原 ZIP 展开，并补入原最终核验对应的四份 PDF。`broad_study/` 保留原研究文件与全部数值输入、结果；七个大文件采用无损 gzip 存储。恢复后原文件大小和 SHA-256 完全一致。

公开阅读所需的变更仅涉及仓库入口、文件导航、便携复算脚本和大文件存储。综合报告及离线查询页面中的本机链接调整为仓库／同目录相对链接。科学编码、数值结果和原论文正文保持原版本；`SOURCE_PROVENANCE.json`对来源与公开存储作逐文件记录。

发布包省去可重新安装的运行时二进制、Python 字节码、Word 临时锁文件和逐页视觉核验缩略图，保留最终 PDF 及相应验收记录。复算入口使用公开文件，不依赖私有仓库或原机器目录。

原交付中的“private”“internal”文字与本机路径反映当时的工作稿状态，随版本记录保留。本次公开发布状态由仓库公开性、本说明和根文件清单记录。原论文为研究工作稿，作者与投稿信息按原状态保留。
